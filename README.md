# Magpie 宠物对战

独立安装的 Magpie 插件，使用 `magpie-digital-pet` v0.6.0 中当前出战的宠物，提供中文大厅和双人回合制对战。宠物存档以只读方式打开。

## 安装

开发预览版可通过 GitHub 安装。双方分别在自己的电脑上运行 `magpie plugin add github:Ryzquo/magpie-pet-battle`。也可将本目录复制到各自的电脑后本地安装。

```bash
cd /path/to/magpie-pet-battle
magpie plugin add "$PWD"
```

安装后刷新 Magpie，在左侧「插件」下进入「宠物对战」。确认原「宠物」页已选定出战宠物。插件页面使用 `127.0.0.1:3572`。请在运行对应 Magpie 插件宿主的电脑上打开页面。若已有安装记录但侧栏入口未出现，可在「插件 → 已安装」将「宠物对战」停用后再启用，重新加载插件。若原插件修改过存档位置，在对战插件的选项中将 `petDbPath` 设为同一数据库的绝对路径。配置修改未立即生效时，重启对应的 Magpie 实例。

## 在线对战

默认使用共享中继 `https://lindum.top/petbattle`。安装后，双方进入大厅并点击「开启在线发现」。一方在在线列表里点击「挑战」，好友接受后进入同一房间。双方同时挑战时，由看到「收到的挑战」的一方接受。取消或超时会关闭待加入的房间。

在线发现、挑战和房间均由同一个中继提供。要使用自己的中继，在插件选项中设置 `relayUrl` 并重启对应的 Magpie 实例。留空时使用共享中继。

## 形象与属性

对战页会读取「宠物」插件的当前出战宠物：大厅、在线玩家列表和战斗舞台显示像素形象，战斗结算时同时播放招式与受击、反击、回血和胜负动作；同时显示疫苗/病毒/数据属性和饱食、心情、精力、清洁、亲密状态。形象资源来自 `magpie-digital-pet` 的 `sprites/` 目录，无需额外配置；没有对应形象的宠物仍显示默认头像。

## 对战码

可直接在大厅创建房间并分享 8 位对战码，好友使用同一个中继输入代码加入。

## 自建中继

房间服务使用 Node.js 22 或更新版本，无需安装 npm 依赖。

```bash
cd /path/to/magpie-pet-battle
node server.mjs
```

云平台可使用仓库根目录的 `Dockerfile` 部署单个常驻实例，配置平台提供的 HTTPS 入口和健康检查路径 `/health`。容器监听 `0.0.0.0`，依次读取 `ARENA_PORT`、平台的 `PORT`，默认端口为 `3574`。房间保存在该实例的内存中，实例重启会结束当前对局。使用 0.2.0 战斗规则时，两端插件和房间服务都需升级。

直接用 Node 启动时默认监听 `127.0.0.1:3574`，`GET /health` 可检查运行状态。可通过 `ARENA_HOST` 和 `ARENA_PORT` 指定监听地址和端口。生产环境可配置 HTTPS 反向代理，将 `/health` 和 `/arena/v2/*` 转发到服务，然后在两边填写同一个 HTTPS 地址。以下以已部署 HTTPS 服务为例。

```bash
magpie plugin options magpie-pet-battle '{"relayUrl":"https://battle.example.com"}'
```

已有 `petDbPath` 时，在同一个 JSON 中保留它。房间在中继内存中保存，中继重启后需要重新建房。

已部署的中继升级时，把 [docs/relay-upgrade.md](docs/relay-upgrade.md) 交给维护者即可：其中列出需要覆盖的文件、重启命令和验证方式。`GET /health` 返回的 `features` 包含 `combat-stats` 表示已运行新版。

## 对战规则

大厅和房间会显示当前出战形态的图鉴力量与闪避。对战基础攻击、防御、活力各有 2 点，再按力量、闪避、固定权重 50 的比例分配其余 6 点，总计 12 点。新版中继使用这套换算，旧客户端或读取不到原数值时沿用按物种分配的基础属性。进房后可自由分配 6 点到攻击、防御和活力，并从破甲、护盾、反击、蓄力、重击、回复中选择两项技能。普攻固定可用。进化阶段不额外增加属性预算。双方可以先查看彼此的配装，各自点击「准备」后锁定。

每回合有 45 秒选招。结算前仅公开是否锁招，结算后显示双方招式、伤害、回复与能量变化。初始能量为 2，上限为 5，普攻回能，部分技能耗能或进入冷却。单方超时额外损失 5 点生命。先把对手生命降到 0 的一方获胜，同时降到 0 则平局。打满 12 回合按剩余生命百分比判定。短时网络中断或页面刷新后，同一插件进程仍可恢复房间。

战斗舞台会从本机已安装的宠物插件读取精灵帧。缺少对应帧时使用会动的原创宠物。双方锁招后，舞台按出招、受击、反击或回复的顺序演出并更新血条。战报默认折叠。开启系统的减少动态效果，或刷新、重连时，舞台直接显示最近的结算。对战码服务也需要包含舞台这次更新，才能提供逐回合动画数据。
