# 无尽冒险

## 入口和职责

大厅提供单人冒险和已解锁的展示奖励。一次冒险绑定开局宠物的快照，读取原宠物存档的行为沿用现有只读接口。冒险战斗在本机页面服务内推进，无需在线席位或中继结算。玩家在多人房间或等待对手接受挑战时先返回大厅再操作冒险。

## 状态与生命周期

同一本机用户数据目录保存一个冒险槽位。新冒险从图鉴可追溯的最低阶段开始；多个合法候选由玩家选择。实际图鉴适配器给出起点和后续分支。缺失图鉴时从当前形态出发。选项随本次冒险快照保存。

手动出招推进一轮，敌方行动意图在出招前展示。冒险复用 PvP 的配装预算、战斗舞台、技能反馈和伤害结算，独立控制敌方决策、跨关生命、奖励和终局。一次出招提交双方行动与最终状态，舞台按顺序播放此次提交中的行动。恢复存档和重连直接呈现最新状态。普通战后选择强化，每五关挑战首领，首领前选择恢复或额外精英战。进化保留已获得的构筑。已无更高形态时仍可选择专精。阵亡或确认结束后保留结算和永久解锁，允许创建下一局。

## 战斗布景

单人战斗的视觉组合由页面按存档中的开局种子、楼层和遭遇身份推导。每五关共用地貌，每场从对应地貌的素材池摆放远景和侧边物件，并选择光照。首领保留专属地标。旧存档用稳定的默认种子，切换形态、出招、退出和重连都不会重抽当前布景。此选择只影响画面，与战斗和强化结算独立。

## 持久化与重试

冒险槽位、最高通关数、解锁和装备放在插件自己的 SQLite 数据库。每次动作携带上次读取的修订号，服务在同一事务中验证修订、结算行动、生成候选、发放解锁并提交。向侧栏返回成功时进度已落盘。过期页面重新读取快照再决定行动。同一进度不能被重复消费。保存退出返回大厅，继续冒险从最后提交的选择点恢复。

## 多人展示

玩家选择装备的称号与出场特效随建房或加入时的宠物快照发送。中继仅接收约定的展示值，原有对战预算、伤害与 Token 结算独立。兼容旧房间的缺省值为空。奖励达成后立即解锁，结束冒险后仍可装备。

## 验证边界

在隔离路径运行本机页面服务，通过页面 API 推进游戏；在独立进程重新打开存档，比较生命、技能状态、路线与候选，并从已保存的进化点继续。覆盖过期修订、重复操作、终局解锁保留和跨首领周期推进。多人使用临时中继验证房间展示。
