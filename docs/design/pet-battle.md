# Magpie 宠物对战

## 职责与入口

插件提供 Magpie 侧栏大厅和一对一房间。从 `magpie-digital-pet` 的 SQLite 存档读取当前出战宠物，读取适配器只依赖 v0.6.0 的存档结构。对战结果保留在房间内，不写回宠物成长数据。

插件通过一个中继访问在线大厅和房间服务。启动时解析 `relayUrl`，空值使用插件声明的共享中继，自定义地址应用于发现和所有房间操作。开启在线发现后，插件定期向中继登记出战宠物并读取在线列表与邀请。对战码入口直接访问同一房间服务。结算和房间生命周期由中继管理。

## 生命周期

发起在线挑战时在中继临时创建房间，发起方留在大厅，受邀方占座后才切换到房间。互相挑战时按发现标识确定唯一可接受的邀请，加入后关闭另一间临时房间。取消或过期会关闭尚未加入的临时房间。

本机页面服务处理发现开关、邀请和当前房间会话；页面刷新可重新读取同一插件进程的状态。进入房间时保存宠物摘要及默认配装。等待阶段允许提交配装，双方可查阅对方配装；各自准备后锁定。结算方验证属性预算、技能资格、能量和冷却，双方锁定或到达截止时间后同时结算。轮次或生命条件满足时确定结果。房间与凭据仅存内存，等待房间和闲置房间会过期。

页面保留最近一次成功读取的状态并继续轮询，会话过期时重新加载页面。操作重试沿用原编号，本机页面服务在短时重试窗口内复用该操作的结果。插件重启会丢失本机保存的席位凭据，中继负责回收闲置房间。

## 关键不变量

- 每个席位使用独立凭据，对战码只用于加入。等待阶段最多允许两人占座。
- 本回合结算前，客户端只能观察双方是否已经锁招。过期轮次的行动不得应用到下一回合。
- 两种入口使用相同的战斗规则。图鉴种类决定等预算基础属性的分布，养成进度无额外预算。生命和伤害由配装及回合效果决定。
- 在线发现和房间 HTTP 路径随不兼容的战斗规则一起升级，避免不同规则的客户端混局。

## 验证标准

验证未配置时使用共享中继、指定地址时使用自定义中继，以及双端在线发现、挑战与接受、对战码加入。两种入口都应完成准备、出招与结算，覆盖掉线恢复、超时及关闭房间。侧栏需验证 Magpie 插件宿主能加载页面并读取配置指定的存档。
