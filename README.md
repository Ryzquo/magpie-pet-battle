# Magpie 宠物对战

独立安装的 Magpie 插件，使用 `magpie-digital-pet` v0.6.0 中当前出战的宠物，提供中文大厅和双人回合制对战。宠物存档以只读方式打开。

## 安装

开发预览版可通过 GitHub 安装。双方分别在自己的电脑上运行 `magpie plugin add github:Ryzquo/magpie-pet-battle`。也可将本目录复制到各自的电脑后本地安装。

```bash
cd /path/to/magpie-pet-battle
magpie plugin add "$PWD"
```

安装后刷新 Magpie，在左侧「插件」下进入「宠物对战」。确认原「宠物」页已选定出战宠物。插件页面使用 `127.0.0.1:3572`。请在运行对应 Magpie 插件宿主的电脑上打开页面。若已有安装记录但侧栏入口未出现，可在「插件 → 已安装」将「宠物对战」停用后再启用，重新加载插件。若原插件修改过存档位置，在对战插件的选项中将 `petDbPath` 设为同一数据库的绝对路径。配置修改未立即生效时，重启对应的 Magpie 实例。

## 局域网对战

双方进入大厅并开启「局域网发现」。一方在附近玩家列表点击「挑战」，留在大厅等待好友接受。好友接受后双方进入同一房间，准备后开始。如果双方同时点击了「挑战」，由看到「收到的挑战」的一方接受。主持房间的 Magpie 负责本局结算。

发现使用 IPv4 组播 `239.255.77.82:35733/UDP`，对局连接使用房主和受邀方插件打开的 TCP 端口。请确认两台电脑接入同一支持组播的局域网。macOS 如弹出本地网络访问提示，请允许 Magpie 访问。跨网段或受访客 Wi-Fi 隔离、防火墙影响时，可配置同一个中继并使用对战码。

## 在线对战（公网发现）

配置 `relayUrl` 后，大厅的「开启发现」会切换为「开启在线发现」：插件每隔几秒把在线状态上报到房间服务，并从同一个服务读取在线玩家和收到的挑战。双方不必处于同一局域网，挑战、建房和对局都经该服务转发，插件端不需要公网 IP 或端口映射。

插件默认使用 `https://lindum.top/petbattle`，安装后无需配置即可在线对战。要部署自己的房间服务时再覆盖该地址（`localhost` 之外的 HTTP 只接受 IP 地址，公网部署建议使用 HTTPS）：

```bash
magpie plugin options magpie-pet-battle '{"relayUrl":"https://your-relay.example.com"}'
```

双方进入大厅并开启「在线发现」，在在线玩家列表点击「挑战」，好友在接受后进入同一房间。房间保存在服务端内存中，服务重启会结束当前对局。未配置 `relayUrl` 时，「开启发现」仍使用局域网组播。

## 对战码

双方的 `relayUrl` 须指向同一个房间服务。房间服务独立运行，使用 Node.js 22 或更新版本，无需安装 npm 依赖。

```bash
cd /path/to/magpie-pet-battle
node server.mjs
```

云平台可使用仓库根目录的 `Dockerfile` 部署单个常驻实例，配置平台提供的 HTTPS 入口和健康检查路径 `/health`。容器监听 `0.0.0.0`，依次读取 `ARENA_PORT`、平台的 `PORT`，默认端口为 `3574`。房间保存在该实例的内存中，实例重启会结束当前对局。使用 0.2.0 战斗规则时，两端插件和房间服务都需升级。

直接用 Node 启动时默认监听 `127.0.0.1:3574`，`GET /health` 可检查运行状态。局域网自用可通过 `ARENA_HOST` 绑定服务器的局域网地址，`ARENA_PORT` 可调整端口。异地对战可在该服务前配置 HTTPS 反向代理，将 `/health` 和 `/arena/v2/room` 转发到服务，然后在两边填写 HTTPS 地址。以下以已部署 HTTPS 服务为例。

```bash
magpie plugin options magpie-pet-battle '{"relayUrl":"https://battle.example.com"}'
```

已有 `petDbPath` 时，在同一个 JSON 中保留它。一方点击「创建房间」并发送 8 位对战码，另一方输入后加入。房间在内存中保存，房主或房间服务重启后需要重新建房。

## 对战规则

宠物按图鉴种类分为强攻、坚守、耐力三种类型，总基础属性都是 12 点。进房后可自由分配 6 点到攻击、防御和活力，并从破甲、护盾、反击、蓄力、重击、回复中选择两项技能。普攻固定可用。进化阶段不额外增加属性预算。双方可以先查看彼此的配装，各自点击「准备」后锁定。

每回合有 45 秒选招。结算前仅公开是否锁招，结算后显示双方招式、伤害、回复与能量变化。初始能量为 2，上限为 5，普攻回能，部分技能耗能或进入冷却。单方超时额外损失 5 点生命。先把对手生命降到 0 的一方获胜，同时降到 0 则平局。打满 12 回合按剩余生命百分比判定。短时网络中断或页面刷新后，同一插件进程仍可恢复房间。
