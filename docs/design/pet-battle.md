# Magpie 宠物对战

## 职责与入口

侧栏从 `magpie-digital-pet` 的 SQLite 存档只读加载当前出战宠物。本机服务为页面提供大厅、邀请和房间操作，解析 `relayUrl` 并维护席位会话。共享中继和自建中继使用相同的在线挑战与对战码入口。

中继负责配装校验、行动权、截止时间、战斗事件与赛果。房间只在进程内存中存在。Token 钱包跨房间持久化，由中继写入独立的 SQLite 数据库。图鉴与养成数据继续由宠物插件管理。

## 生命周期

在线挑战先创建等待房间，对方接受才进入战斗页面。互相挑战时按发现标识选择可接受的邀请，取消或过期会关闭无人加入的房间。双方准备后中继随机选出先手，逐手验证行动并公布结果。开局后手倒地时，符合复活条件则进入一次限时选择，选择结束后再判断胜负。

本机保存席位凭据以支持页面刷新。每份有效行动绑定席位与手次；重试不能推进下一手。舞台将连续行动事件显示为出招、命中、反击或回复，血条跟随命中点推进。重连、事件跳号或减少动态效果时直接显示当前状态。

## 钱包与身份

本机为每个中继保存私有身份密钥，建房或加入时提供给该中继。中继通过密钥派生钱包身份。大厅发现标识、房间码和宠物名称均无权支配余额。结算按唯一对局标识把双方流水与余额一次写入事务，重复读取终局应返回相同的实计变动和当时余额。本期只提供战斗入账能力。

## 关键不变量与验证

- 在线挑战与对战码共用 v3 协议。旧规则客户端不能加入交替行动房间。
- 每个席位使用独立凭据，只有当前行动席可出招。普通超时、复活选择以及最后一手均由中继裁定。
- 两席具有相同的属性与技能位预算。固有技能独立于两个通用装备位。客户端以中继返回的数值绘制伤害与恢复。
- 验证同一席位重复操作、跨席位越权、超时、反击双倒、最后一手复活以及 Token 入账重试和重启恢复。
- 双端检查行动交接、受击帧与血条同步、窄侧栏和减少动态效果。宿主集成需使用已安装的 Magpie 与宠物插件检查。
