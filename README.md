# Magpie 宠物对战

独立安装的 Magpie 插件，使用 `magpie-digital-pet` v0.6.0 中当前出战的宠物，提供中文大厅和双人回合制对战。宠物存档以只读方式打开。

## 安装

开发预览版可通过 GitHub 安装。双方分别在自己的电脑上运行 `magpie plugin add github:Ryzquo/magpie-pet-battle`。也可将本目录复制到各自的电脑后本地安装。

```bash
cd /path/to/magpie-pet-battle
magpie plugin add "$PWD"
```

安装后刷新 Magpie，在左侧「插件」下进入「宠物对战」。确认原「宠物」页已选定出战宠物。插件页面使用 `127.0.0.1:3572`。请在运行对应 Magpie 插件宿主的电脑上打开页面。若已有安装记录但侧栏入口未出现，可在「插件 → 已安装」将「宠物对战」停用后再启用，重新加载插件。若原插件修改过存档位置，在对战插件的选项中将 `petDbPath` 设为同一数据库的绝对路径。配置修改未立即生效时，重启对应的 Magpie 实例。

## 在线对战

默认使用共享中继 `https://lindum.top/petbattle`。安装后，双方进入大厅并点击「开启在线发现」。一方在在线列表里点击「挑战」，好友接受后进入同一房间。双方同时挑战时，由看到「收到的挑战」的一方接受。取消或超时会关闭待加入的房间。

在线发现、挑战和房间均由同一个中继提供。要使用自己的中继，在插件选项中设置 `relayUrl` 并重启对应的 Magpie 实例。留空时使用共享中继。

## 形象与属性

对战页会读取「宠物」插件的当前出战宠物：大厅、在线玩家列表和战斗舞台显示像素形象，战斗结算时同时播放招式与受击、反击、回血和胜负动作；同时显示疫苗/病毒/数据属性和饱食、心情、精力、清洁、亲密状态。形象资源来自 `magpie-digital-pet` 的 `sprites/` 目录，无需额外配置；没有对应形象的宠物仍显示默认头像。

## 对战码

可直接在大厅创建房间并分享 8 位对战码，好友使用同一个中继输入代码加入。

## 自建中继

中继推荐使用 Node.js 24 LTS，自带 SQLite，无需安装 npm 依赖。

```bash
cd /path/to/magpie-pet-battle
node server.mjs
```

云平台可使用仓库根目录的 `Dockerfile` 部署单个常驻实例，配置平台提供的 HTTPS 入口和健康检查路径 `/health`。容器监听 `0.0.0.0`，依次读取 `ARENA_PORT`、平台的 `PORT`，默认端口为 `3574`。房间保存在该实例的内存中，实例重启会结束当前对局。交替行动使用 v3 协议，两端插件和中继需同时升级。Token 钱包存入单独的 SQLite 数据库，部署时应挂载持久卷。

直接用 Node 启动时默认监听 `127.0.0.1:3574`，`GET /health` 可检查运行状态。可通过 `ARENA_HOST` 和 `ARENA_PORT` 指定监听地址和端口。生产环境可配置 HTTPS 反向代理，将 `/health` 和 `/arena/v3/*` 转发到服务，然后在两边填写同一个 HTTPS 地址。以下以已部署 HTTPS 服务为例。

```bash
magpie plugin options magpie-pet-battle '{"relayUrl":"https://battle.example.com"}'
```

已有 `petDbPath` 时，在同一个 JSON 中保留它。房间在中继内存中保存，中继重启后需要重新建房。

已部署的中继升级时，把 [docs/relay-upgrade.md](docs/relay-upgrade.md) 交给维护者即可：其中列出需要覆盖的文件、重启命令和验证方式。`GET /health` 返回的 `features` 包含 `alternating-turns` 和 `token-wallet` 表示支持交替行动和持久 Token 钱包。

## 对战规则

图鉴力量与闪避决定基础攻击、防御和耐力的分配，总计 12 点。读取不到图鉴数值时按物种分配。进房后再分配 6 点并选两项通用技能。双方可查看彼此的配置，点击「准备」锁定。每只宠物自带普攻和一项固有技能。耐力影响生命上限，战斗体力用于释放技能，体力达标后固有技能亮起。

中继随机决定先手。双方轮流行动，每手 60 秒，各有最多 12 手。招式一经接受即结算，普通行动超时跳过并损失 5 点生命。护盾和反击覆盖对手下一手，蓄力持续到下次主动攻击。双方用完行动次数时按剩余生命比例判胜，比例相同为平局。

复活占一个通用技能位。开局后手倒地且仍有行动次数时，可在 60 秒内选择复活或放弃。复活占一手，每场一次，恢复最大生命的 30%（向上取整）。在复活选择结束前，双方均可查看倒计时，Token 延后结算。

胜利 +3 Token、平局 +1、落败 −1、主动认负 −3，每次超时另扣 1。获得正向赛果奖励需要至少有效出招一次。余额最低为 0，结算页显示应计与实计金额。钱包随本机安装身份按中继独立保存，余额和流水由中继持久化。准备阶段离房不计分。

每次有效行动由中继发出事件，舞台按命中时刻更新血条，区分直接伤害、反击与回复。减少动态效果、刷新或重连时直接显示当前状态。
